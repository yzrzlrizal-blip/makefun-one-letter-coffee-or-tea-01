One letter, one answer: **A — coffee**. A tiny Node program that writes exactly one letter, A for coffee, to `/output/entry.txt` for make.fun's "One Letter: Coffee or Tea" bounty. Coffee is the bolder, more vivid answer: dark, hot, strong, the morning ritual that wakes the day up.

## Run it

```sh
node main.ts
```
